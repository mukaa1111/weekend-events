# 주말 뭐하지? — 대전 초2 남아 행사 알리미 (PRD)

작성일: 2026-10-16 · 상태: 기획 확정, 구현 전

## 한 줄 소개
대전과 차로 1시간 안쪽(세종·청주·공주·논산 등)에서 초등 2학년 남자아이들이 주중·주말에 참여할 만한
교육·체험·행사 정보를 한 곳에 모아, 매주 10분 안에 "이번 주말 갈 곳"을 고를 수 있게 해주는 가족용 페이지 + 수집 에이전트.

## 누가 쓰나
- 우리 가족(보호자 1명). 로그인·공유 없음.
- 보호자가 매주 목요일쯤 열어 보고, 주말 일정을 정한다.
- 아이 2명(초2 남아) 기준으로 대상 연령·난이도를 걸러 본다.

## 핵심 기능 (6개)
1. **이번 주말 · 다음 주말 행사 목록** — 날짜/시간, 장소, 비용(무료·유료), 예약 필요 여부, 대상 연령, 출처 링크를 한 줄로 보여준다.
2. **미리 체크할 큰 행사** — 약 6주 안의 대형 축제·예약이 빨리 마감되는 행사를 따로 모아 보여준다. 서울·부산·강원 등 전국 대형 어린이 행사도 "있을 때만" 이 묶음에 추가된다.
3. **정해둔 출처 정기 수집** — 아래 출처 목록을 에이전트(Claude Code)가 돌며 새 행사를 찾아 `data/events.js`에 쌓는다. 블로그·인스타그램의 "요즘 추천" 정보로 보완한다. 잘쓸레터(어피티) 같은 뉴스레터는 **내가 붙여넣지 않고 에이전트가 직접 읽는다** — 뉴스레터에 공개 웹페이지(지난 호 보관함)가 있으면 거기서 읽고, 없으면 Gmail을 Claude에 한 번 연결해 두고 그 발신자에게서 온 새 메일을 자동으로 찾아 행사만 뽑아 넣는다.
4. **분야 태그와 간단 필터** — 과학·만들기·코딩 / 운동·야외·자연 / 예술·공연·전시 / 축제·역사·도서관, 무료·유료, 지역(대전 / 근교 / 전국)으로 거른다.
5. **"다른 지역도 찾아줘" 요청** — 채팅으로 "강원도 큰 어린이 행사 찾아줘"라고 하면 그 결과를 전국 묶음에 추가한다.
6. **출처 쉽게 추가·삭제** — 출처 목록은 파일 하나(`data/sources.js`: 이름, 주소, 지역, 종류)로 관리한다. 채팅으로 "출처에 ○○ 추가해줘 (주소)"라고 하면 에이전트가 파일에 넣고 다음 수집부터 반영한다. 페이지 아래에 "지금 보는 출처" 목록을 보여줘 무엇이 들어 있는지 바로 확인할 수 있다. 블로그·인스타 계정, 뉴스레터도 같은 방식으로 추가한다.

## 수집 출처 (초안 — 확인 후 추가/삭제, 확정되면 `data/sources.js`으로 옮김)
| 지역 | 출처 |
|---|---|
| 대전 | 국립중앙과학관(교육·행사), 대전시립미술관·이응노미술관·대전시립박물관, 대전광역시 문화관광 행사달력, 대전광역시 통합도서관(한밭도서관 등), 대전시민천문대, 대전교육과학연구원 |
| 근교 | 국립세종도서관, 세종시문화관광재단, 국립청주박물관 어린이박물관, 국립현대미술관 청주, 국립공주박물관, 논산시 축제 안내 |
| 보완 | 네이버 블로그·인스타그램 "대전 아이와 주말" 류 추천 글, 잘쓸레터(어피티) 즐길거리 소식(웹 보관함 또는 Gmail 자동 읽기) |
| 전국(큰 것만) | 국립중앙박물관 어린이박물관, 국립과천과학관, 대형 어린이 축제·박람회 |

## 이번엔 안 할 것
- 회원가입·로그인, 여러 가족과 공유, 댓글·후기
- 스마트폰 앱(앱스토어), 데이터베이스, 서버 운영
- 카카오톡 알림 (사업자 채널 심사가 필요해서 보류 → 텔레그램으로 대체)
- 예약·결제 기능, 지도 표시, 길찾기
- 수집 정보의 100% 정확도 보장 (출처 링크로 직접 확인하는 걸 전제)

## 단계별 목표
- **1단계 (이번 주)**: PC에서 더블클릭으로 여는 페이지 1장 + 손으로 넣은 예시 행사
- **2단계**: "이번 주 행사 수집해줘" 한마디로 에이전트가 목록 갱신
- **3단계**: 매주 목요일 자동 수집 + 폰에서도 보기(무료 호스팅)
- **4단계**: 텔레그램으로 목요일 요약 알림

## 성공 기준
- 매주 목요일, 페이지를 열고 10분 안에 이번 주말 갈 곳 1곳을 정할 수 있다.
- 세종 한글축제처럼 큰 행사를 "전날"이 아니라 최소 2주 전에 안다.
- 한 달 운영 후, 목록에서 실제로 간 행사가 2건 이상이다.

## 기술 (가장 단순한 방식)
| 역할 | 선택 | 이유(한 줄) |
|---|---|---|
| 화면 | HTML 파일 1개(`index.html`) + 데이터 파일 2개(`data/events.js` 행사, `data/sources.js` 출처) | 설치·서버·로그인 없이 더블클릭으로 열린다. 데이터를 .json이 아닌 .js로 둔 이유: 더블클릭으로 연 페이지는 보안상 .json을 못 읽지만 .js는 읽을 수 있다 |
| 수집 에이전트 | Claude Code(지금 쓰는 이 도구) | 웹 검색·요약·파일 쓰기를 이미 다 하고, 새 도구를 배울 필요가 없다 |
| 자동 실행 | Claude Code 예약 실행(스케줄) | 매주 목요일에 수집 지시문을 자동으로 돌릴 수 있다 |
| 폰에서 보기 | GitHub Pages(무료 호스팅) | 파일을 올려두기만 하면 주소가 생기고 비용이 없다 |
| 알림 | 텔레그램 봇 | 카톡과 달리 개인이 10분 만에 만들 수 있다 |
| 뉴스레터 읽기 | 웹 보관함 우선, 없으면 Gmail 연결(Claude 커넥터) | 한 번 연결해 두면 메일을 열어볼 필요 없이 에이전트가 읽는다 |
| 안 쓰는 것 | 데이터베이스, 프레임워크, 서버 | 가족용 수십 건 데이터엔 과하다 |
