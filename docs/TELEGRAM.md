# 텔레그램 알림 설정 (TELEGRAM)

월·목 아침 자동 수집이 끝나면 텔레그램으로 "이번 주말 추천 3곳 + 예약 서두르기(7일 안 접수 마감·시작) + 페이지 주소"를 보내줘요.

## 한 번만 하면 되는 준비 (약 5분, 직접 해야 함)

### 1. 봇 만들기 (텔레그램 앱에서)
1. 텔레그램 검색창에 **BotFather** 를 찾아 대화 시작 (파란 체크 표시가 있는 공식 계정)
2. `/newbot` 입력
3. 봇 이름을 물으면 아무거나: 예) `주말 뭐하지 알리미`
4. 봇 아이디를 물으면 영문으로, 끝이 `bot`으로 끝나야 함: 예) `jumal_mwohaji_bot` (이미 있다고 하면 숫자 붙이기)
5. BotFather가 **토큰**을 줘요. `123456789:AAH...` 같은 긴 글자예요.
   **이 토큰은 비밀번호예요. 채팅에 붙여넣지 말고 4번에서 직접 입력하세요.**

### 2. 내 chat id 알아내기
1. 텔레그램 검색창에 **userinfobot** 을 찾아 대화 시작 → `/start`
2. `Id: 123456789` 처럼 숫자가 나와요. 이게 **chat id**예요. (비밀은 아니지만 굳이 공유할 필요 없음)

### 3. 봇과 대화 시작해 두기
- 1번에서 만든 봇을 검색해서 열고 **시작(Start)** 버튼을 한 번 눌러요. 이걸 안 하면 봇이 나한테 먼저 메시지를 못 보내요.

### 4. 클라우드 환경에 값 넣기
1. https://claude.ai/code → 아래쪽 **Default**(환경) → **클라우드 ›** → Default 설정 열기
2. **환경 변수**(Environment variables) 항목에 두 줄 추가:
   - 이름 `TELEGRAM_BOT_TOKEN` / 값: 1번에서 받은 토큰
   - 이름 `TELEGRAM_CHAT_ID` / 값: 2번에서 받은 숫자
3. 저장

### 5. 확인
- Claude에게 "텔레그램 시험 발송해줘"라고 하면 루틴을 한 번 돌려서 메시지가 오는지 확인해요.

## 동작 방식
- 수집 루틴이 끝날 때 `scripts/telegram.sh "메시지"` 를 실행해요.
- 환경 변수가 없으면 스크립트가 조용히 건너뛰어요 (수집 자체는 영향 없음).
- 메시지는 글자만(링크 미리보기 없음), 4,000자 안쪽으로 잘라요.

## 메시지 예시
```
📅 주말 뭐하지? 10/19(월) 수집 결과
추가 2 · 갱신 1 · 삭제 3

이번 주말(10/24~25) 추천
1. 국립청주박물관 가을 음악회 '쉼포니' — 10/24(토) 13:30, 무료, 예약 불필요(현장접수)
2. 국립중앙과학관 별의별 과학특강 — 10/24(토), 무료, 예약 필요(선착순)
3. 국립공주박물관 이끼 테라리움 만들기 — 10/24(토) 14:00, 무료, 예약 필요(마감 10/23)

예약 서두르기 (7일 안)
- 국립공주박물관 이끼 테라리움(행사일 10/24) — 접수 마감 10/23(금), 누리집 선착순
- 온 시민 에너지걷기(행사일 11/15) — 접수 마감 10/31(토), 사전등록 선착순

전체 보기: https://mukaa1111.github.io/weekend-events/
```

## 계정 옮길 때
- 봇과 토큰은 **내 텔레그램 계정** 것이라 그대로 써요.
- 새 Claude 계정의 클라우드 환경에 4번(환경 변수)만 다시 넣으면 돼요.
