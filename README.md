# 주말 뭐하지? — 사용 안내

대전 + 근교에서 초등 2학년 아이들과 갈 만한 행사를 모아 보는 가족용 페이지예요.

## 여는 법
- **폰이나 어디서든**: https://mukaa1111.github.io/weekend-events/ 를 열면 돼요.
- **앱처럼 설치**: 아이폰은 Safari에서 공유(□↑) → "홈 화면에 추가", 안드로이드는 Chrome 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치". 주황색 달력 아이콘이 생기고 전체 화면으로 열려요.
- **PC에서 파일로**: 이 폴더의 `index.html`을 더블클릭해도 같은 화면이 떠요.
- 파일을 고친 뒤 폰 주소에도 반영하려면 "GitHub에 올려줘"라고 말하면 돼요. 자동 수집은 알아서 올라가요.

## 파일 설명
| 파일 | 뭐 하는 파일인가 |
|---|---|
| `index.html` | 화면. 건드릴 일 거의 없어요. |
| `data/events.js` | 행사 목록. 에이전트가 수집해서 채우고, 직접 고쳐도 돼요. |
| `data/sources.js` | 수집 출처 목록. "출처에 ○○ 추가해줘"라고 하면 여기 추가돼요. 주소 대신 검색어로 된 "검색형" 출처도 있어요 (사이트가 안 열리는 구청·재단용). |
| `docs/PRD.md` | 무엇을 만드는지 정리한 기획서 |
| `docs/PLAN.md` | 만드는 순서 체크리스트 |
| `docs/COLLECT.md` | 수집 규칙 (에이전트가 매번 읽음) |
| `docs/ROUTINE.md` | 자동 수집 예약 설정. 다른 Claude 계정으로 옮길 때 이걸로 다시 만들면 됨 |
| `docs/TELEGRAM.md` | 텔레그램 알림 설정법 (봇 만들기, 환경 변수) |
| `scripts/telegram.sh` | 수집 끝나면 텔레그램으로 요약을 보내는 작은 스크립트 |

## 자동 수집
- 매주 **월요일·목요일 아침 7시**에 클라우드에서 자동으로 행사를 모아 GitHub에 올려요. 폰 주소에 바로 반영돼요.
- 예약 확인·끄기·지금 실행: https://claude.ai/code/routines/trig_01KxcHeuUARbcQ3ZKNuaYTAh
- 저녁 9시 회신 반영 루틴: https://claude.ai/code/routines/trig_01ULJVVdobwpSBcHaJkGsaVW
- 수집 규칙을 바꾸고 싶으면 `docs/COLLECT.md`를 고치면 돼요 (에이전트가 매번 이 문서를 읽어요).
- 수집이 끝나면 텔레그램으로 "이번 주말 추천 3곳 + 예약 서두르기" 요약이 와요 (설정: `docs/TELEGRAM.md`).
- **매일 아침 7시 30분**에는 그날 접수가 시작·마감되는 행사가 있을 때만 "⏰ 오늘 접수 알림"이 와요.
- **텔레그램 답장으로 행사 요청**: 알림에 행사명을 답장하면 밤 9시에 찾아서 추가해요. "○○ 빼줘"도 돼요. 자세한 건 `docs/TELEGRAM.md`.

## 자주 쓰는 말 (Claude에게)
- "이번 주 행사 수집해줘" → `data/events.js` 갱신 (2단계부터)
- "출처에 ○○ 추가해줘 (주소)" → `data/sources.js`에 추가
- "강원도 큰 어린이 행사 찾아줘" → 전국 묶음에 추가

## 화면 묶음 설명
- **이번 주말 추천 3곳**: 맨 위에 고정. 수집할 때 에이전트가 다음 토·일에 갈 만한 3곳을 이유 한 줄과 함께 골라요 (텔레그램 추천과 같은 3곳). 그 사이 마감되면 자동으로 빠지고 다른 행사가 채워져요. 필터를 켜면 조건에 맞는 것으로 다시 골라요
- **♥ 찜한 행사**: 카드 오른쪽 위 **♡**를 누르면 맨 위에 모여요. **이 폰(브라우저)에만** 저장되니 다른 폰에선 안 보이고, 브라우저 데이터를 지우면 사라져요
- **예약 서두르기**: 7일 안에 접수가 **시작**되거나 **마감**되는 행사를 한 줄씩 보여줘요 (D-2 접수 마감 11/13 식). 줄을 누르면 아래에 있는 그 행사 카드로 이동해서 펼쳐져요. 인기 프로그램은 오픈 직후 마감되니 시작일 기준으로도 올라와요
- **이번 주 · 주말**: 오늘부터 이번 일요일까지 (추천 3곳에 올라간 행사는 여기서 빠져요). 2주 넘게 이어지는 전시·체험은 아래 "계속 진행 중"에 접혀 있어요 (끝나는 날 순)
- **다음 주말**: 다음 월요일부터 일요일까지
- **미리 체크할 큰 행사**: 약 6주 안의 큰 행사 (`big: true`)
- **전국 큰 행사**: 지역이 `전국`인 행사
- **접수가 끝난 행사**: 인원 마감·접수 종료로 지금은 신청할 수 없는 행사 (접혀 있음). 취소 자리가 날 수 있어 지우지는 않아요. 카드에 "마감" 표시와 사유가 붙어요
- **다녀온 곳**: 텔레그램에 "갔어 ○○ 한 줄 감상"이라고 답장하면 쌓이는 기록 (접혀 있음). 이번 달·전체 횟수가 보여요. 다녀온 행사는 카드에 "✔ 다녀옴"이 붙고 추천에서 빠져요
- **그 이후 행사**: 위에 안 들어간 나머지 (접혀 있음)
- 대전 밖 행사는 장소 옆에 **🚗 차 50분**처럼 대전에서 가는 시간이 붙어요 (도시별 기준표, 둔산 출발 기준 대략값).
- 카드 왼쪽의 아이콘은 분야(🔬 과학 · 🌳 야외 · 🎭 예술 · 🎪 축제)예요. 공식 포스터 주소가 있는 행사는 아이콘 대신 작은 사진이 보여요.
- 필터의 **☔ 비 와도 OK**를 누르면 실내(또는 실내 공간이 있는) 행사만 보여요. 카드마다 실내/야외/실내+야외 표시가 붙어요.
- **카드는 요약만** 보여요: 제목, 날짜, 시간·장소, 상태 표시(무료/유료, 예약 상태, 실내/야외), 메모 두 줄. 카드 아래 **"자세히 · 길찾기"**를 누르면 시간·대상·비용·접수 방법·출처와 **길찾기**(네이버지도)·**캘린더**(구글 캘린더에 넣기)·**공유**(카톡 등으로 보내기) 버튼이 펼쳐져요.
- **필터**는 맨 위 "필터" 버튼 안에 접혀 있어요. 조건을 켜면 버튼이 검게 바뀌고 켜진 조건이 버튼에 적혀요.
- 예약이 필요 없는 행사는 **예약 없이 OK** 표시가 붙어요.
- 예약 상태는 배지 하나로 보여요: **예약 없이 OK** / **예약 필요 · 마감 11/13(금) · D-2** / **접수 시작 11/16(월) 10:00 · D-5** / **마감**. 7일 안이면 주황, 3일 안이면 빨강이에요. 오래 이어지는 전시·체험은 날짜 옆에 "종료 D-3"이 붙어요 (접수 D-day가 이미 있으면 생략).
- 지난 행사는 자동으로 숨겨져요. "확인 필요" 표시는 아직 공식 페이지로 확인 안 한 정보예요.
