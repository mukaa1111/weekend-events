# 주말 뭐하지? — 사용 안내

대전 + 근교에서 초등 2학년 아이들과 갈 만한 행사를 모아 보는 가족용 페이지예요.

## 여는 법
- **폰이나 어디서든**: https://mukaa1111.github.io/weekend-events/ 를 열면 돼요. (홈 화면에 추가해 두면 앱처럼 써요)
- **PC에서 파일로**: 이 폴더의 `index.html`을 더블클릭해도 같은 화면이 떠요.
- 파일을 고친 뒤 폰 주소에도 반영하려면 "GitHub에 올려줘"라고 말하면 돼요. 자동 수집은 알아서 올라가요.

## 파일 설명
| 파일 | 뭐 하는 파일인가 |
|---|---|
| `index.html` | 화면. 건드릴 일 거의 없어요. |
| `data/events.js` | 행사 목록. 에이전트가 수집해서 채우고, 직접 고쳐도 돼요. |
| `data/sources.js` | 수집 출처 목록. "출처에 ○○ 추가해줘"라고 하면 여기 추가돼요. |
| `docs/PRD.md` | 무엇을 만드는지 정리한 기획서 |
| `docs/PLAN.md` | 만드는 순서 체크리스트 |
| `docs/COLLECT.md` | 수집 규칙 (에이전트가 매번 읽음) |
| `docs/ROUTINE.md` | 자동 수집 예약 설정. 다른 Claude 계정으로 옮길 때 이걸로 다시 만들면 됨 |
| `docs/TELEGRAM.md` | 텔레그램 알림 설정법 (봇 만들기, 환경 변수) |
| `scripts/telegram.sh` | 수집 끝나면 텔레그램으로 요약을 보내는 작은 스크립트 |

## 자동 수집
- 매주 **월요일·목요일 아침 7시**에 클라우드에서 자동으로 행사를 모아 GitHub에 올려요. 폰 주소에 바로 반영돼요.
- 예약 확인·끄기·지금 실행: https://claude.ai/code/routines/trig_01KxcHeuUARbcQ3ZKNuaYTAh
- 수집 규칙을 바꾸고 싶으면 `docs/COLLECT.md`를 고치면 돼요 (에이전트가 매번 이 문서를 읽어요).
- 수집이 끝나면 텔레그램으로 "이번 주말 추천 3곳 + 예약 서두르기" 요약이 와요 (설정: `docs/TELEGRAM.md`).

## 자주 쓰는 말 (Claude에게)
- "이번 주 행사 수집해줘" → `data/events.js` 갱신 (2단계부터)
- "출처에 ○○ 추가해줘 (주소)" → `data/sources.js`에 추가
- "강원도 큰 어린이 행사 찾아줘" → 전국 묶음에 추가

## 화면 묶음 설명
- **♥ 찜한 행사**: 카드의 "♡ 찜"을 누르면 맨 위에 모여요. **이 폰(브라우저)에만** 저장되니 다른 폰에선 안 보이고, 브라우저 데이터를 지우면 사라져요
- **예약 서두르기**: 7일 안에 접수가 **시작**되거나 **마감**되는 행사 (있을 때만 맨 위에 보임). 인기 프로그램은 오픈 직후 마감되니 시작일 기준으로도 올라와요
- **이번 주말**: 오늘부터 이번 일요일까지. 2주 넘게 이어지는 전시·체험은 아래 "계속 진행 중"에 접혀 있어요 (끝나는 날 순)
- **다음 주말**: 다음 월요일부터 일요일까지
- **미리 체크할 큰 행사**: 약 6주 안의 큰 행사 (`big: true`)
- **전국 큰 행사**: 지역이 `전국`인 행사
- **그 이후 행사**: 위에 안 들어간 나머지 (접혀 있음)
- 대전 밖 행사는 장소 옆에 **🚗 차 50분**처럼 대전에서 가는 시간이 붙어요 (도시별 기준표, 둔산 출발 기준 대략값).
- 카드 왼쪽의 아이콘은 분야(🔬 과학 · 🌳 야외 · 🎭 예술 · 🎪 축제)예요. 공식 포스터 주소가 있는 행사는 아이콘 대신 작은 사진이 보여요.
- 필터의 **☔ 비 와도 OK**를 누르면 실내(또는 실내 공간이 있는) 행사만 보여요. 카드마다 실내/야외/실내+야외 표시가 붙어요.
- 카드의 **길찾기**(네이버지도)·**캘린더**(구글 캘린더에 넣기)·**공유**(카톡 등으로 보내기) 버튼은 폰에서 바로 눌러 쓰면 돼요.
- "D-3" 표시는 행사 종료나 접수 마감이 7일 안일 때 붙어요. 3일 안이면 빨갛게 보여요.
- 지난 행사는 자동으로 숨겨져요. "확인 필요" 표시는 아직 공식 페이지로 확인 안 한 정보예요.
